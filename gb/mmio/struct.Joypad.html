pub struct Joypad(/* private fields */);
Expand description

Joypad register (JOYP). Active low: a cleared bit means selected, or the input pressed.

BitFieldAccessMeaning
7-6—Unused.
5buttonsR/WSelects the action buttons (A/B/Select/Start).
4dpadR/WSelects the d-pad.
3p13ROInput line P13: Down (d-pad) or Start (buttons).
2p12ROInput line P12: Up (d-pad) or Select (buttons).
1p11ROInput line P11: Left (d-pad) or B (buttons).
0p10ROInput line P10: Right (d-pad) or A (buttons).
