pub struct OamAttr(/* private fields */);
Expand description

Sprite attribute byte (OamEntry::attr).

BitFieldAccessMeaning
7priorityR/WSet draws the sprite behind BG colors 1-3.
6y_flipR/WMirror vertically.
5x_flipR/WMirror horizontally.
4dmg_paletteR/WDMG palette: clear = OBP0, set = OBP1.
3cgb_bankR/WCGB tile VRAM bank.
2-0cgb_paletteR/WCGB object palette (0-7).
