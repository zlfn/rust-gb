Function stream

pub fn stream(dst: u16, src: &'static [u8]) -> Option<Stream>
Available on crate feature cgb only.
Expand description

Start moving src to dst sixteen bytes at a time, one step per HBlank.

None if a transfer is already running. Read Stream before using this: what the program may do while it runs is narrow.

src is 'static because the copier reads it over many frames and a switchable bank would move underneath it. That rules out banked ROM and cartridge RAM, neither of which lends for longer than a scope.
