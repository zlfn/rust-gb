The BankSafe marker.

It lives in its own crate so that gb-bank’s own dependencies can bound their APIs on it. Use it through gb_bank::BankSafe, which re-exports it.

BankSafe
A value safe to carry across a bank switch: it embeds no pointer to banked code that the switch would unmap.
